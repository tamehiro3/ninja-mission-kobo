# CNP にんじゃミッション工房

AIが毎日つくる安全な忍者なぞときで、かわいいニンジャキャラと里を育てるスマホゲーム（PWA）。
小学生向け・保護者安心設計（エロなし／グロなし／血なし／怖すぎる表現なし／自由チャットなし）。

## 遊び方

1. スマホでゲームURLを開く
2. **iPhone**: Safari → 共有ボタン → 「ホーム画面に追加」／**Android**: Chrome → メニュー(⋮) → 「アプリをインストール」
3. ホーム画面のアイコンからアプリとして起動（オフラインでも遊べる）

## 公開方法（PCで1回だけ）

`★ゲームを公開する.bat` をダブルクリック → 画面の指示どおりGitHubにログイン → 完了するとゲームURLが表示・コピーされます。

2回目以降（ゲームを修正したとき）も同じbatをダブルクリックすれば更新されます。

## ゲーム内容（MVP）

| 設計図の項目 | 実装 |
|---|---|
| キャラ3体〜 | リーリー・ミタマ・オロチ（初期）＋ナルカミ・ルナ（アンロック制）の5体 |
| AI任務テンプレート10種類 | なぞなぞ／すいり／じゅんばん／きおく／かんさつ／めいろ／あんごう／さかさことば／ことばならべ／さんすう |
| なぞとき30問〜 | なぞなぞ30問＋すいり12問＋じゅんばん12問＋単語35語＋日替わり自動生成（めいろ・さんすう等は毎日新規生成） |
| 里アイテム30個 | かざり30種（コイン＋素材で購入、ガチャなし・中身が見えるパック） |
| 1日3任務 | 日付シードで毎日変わる任務を3本（保護者設定で1〜5本に変更可） |
| ヒント機能 | 3段階ヒント（使うほど報酬が少し減る） |
| 保護者設定 | かけ算ゲート／任務数／難易度（学年目安）／演出／統計／データリセット |
| 章の進行 | クリア数で第1章はじまりの里→第5章星影の城 |

## 「AI」について

MVPでは、APIコスト・安全性・オフライン動作を優先し、**端末内の日替わりシード生成（テンプレート×素材バンク）**で「毎日変わる任務」を実現しています。自由入力は一切ありません。
将来Claude APIで任務文面を生成する場合も、サーバー側で生成→検品→配信の形を推奨（クライアントにAPIキーを置かない）。

## キャラクターIPについての注意

キャラ名（リーリー等）はCryptoNinja/CNPのキャラクター名を使用した**個人試作**です。
公開範囲を広げる・商用利用する場合は、CryptoNinja公式の利用ガイドライン（CC0の範囲とCNPのライセンス条件）を必ず確認してください。ゲーム内のグラフィックは絵文字と自作アイコンのみで、公式アートは含んでいません。

## 技術構成

- 素のHTML/CSS/JS（ビルド不要）＋PWA（manifest + Service Worker、オフライン対応）
- セーブデータは端末のlocalStorage（サーバー送信なし・個人情報収集なし）
- ホスティング: GitHub Pages

# CNP にんじゃミッション工房

AIが毎日つくる安全な忍者なぞときで、かわいいニンジャキャラと里を育てるスマホゲーム（PWA）。
小学生向け・保護者安心設計（エロなし／グロなし／血なし／怖すぎる表現なし／自由チャットなし）。

## 遊び方

1. スマホでゲームURLを開く
2. **iPhone**: Safari → 共有ボタン → 「ホーム画面に追加」／**Android**: Chrome → メニュー(⋮) → 「アプリをインストール」
3. ホーム画面のアイコンからアプリとして起動（オフラインでも遊べる）

## 公開方法（PCで1回だけ）

`★ゲームを公開する.bat` をダブルクリック → 画面の指示どおりGitHubにログイン → 完了するとゲームURLが表示・コピーされます。

2回目以降（ゲームを修正したとき）も同じbatをダブルクリックすれば更新されます。

## 広告（AdSense）

ホーム画面下部にバナー広告枠が1つあります（「こうこく」ラベル付き）。**なぞとき中・任務画面では表示されない**設計で、`index.html` の `<head>` で非パーソナライズ広告を指定しています（子ども向け配慮）。

- AdSense読み込みタグは `index.html` の `<head>` に1回だけ（`ads.js` からの二重読み込みは廃止）
- `ads.js` の `slot` が空のあいだは広告枠を出しません（仮表示は審査で不利なため）
- オフライン時・広告が配信されなかったとき（`data-ad-status="unfilled"`）は枠ごと隠れます

残りの手順：

1. AdSense管理画面で `tamehiro3.github.io` の承認を確認
2. 「広告 → 広告ユニットごと → ディスプレイ広告」でユニットを作成
3. [ads.js](ads.js) の `slot` にスロットID（数字）を入力
4. `★ゲームを公開する.bat` で再公開

広告を消したいときは `ads.js` の `enabled: false` にするだけです。

遊び方・保護者向けの説明は [about.html](about.html)（保護者設定画面からリンク）。

## 「AI」について

MVPでは、APIコスト・安全性・オフライン動作を優先し、**端末内の日替わりシード生成（テンプレート×素材バンク）**で「毎日変わる任務」を実現しています。自由入力は一切ありません。
将来Claude APIで任務文面を生成する場合も、サーバー側で生成→検品→配信の形を推奨（クライアントにAPIキーを置かない）。

## キャラクターIPについて

登場キャラは **CryptoNinja（CC0ライセンス）** の公式キャラクターです：咲耶（甲賀・召喚術）、ネム（甲賀・絵筆）、シャオラン（甲賀・パンダ召喚、相棒リーリー）、ハヤテ（伊賀・鷹の目）、クオン（雑賀・猫目の道選び）、カルラ（伊賀・雷遁）、イチヤ（雑賀・忍びの暗号）。CryptoNinjaのキャラクターはCC0で公開されており、二次利用が認められています。

ゲーム内のグラフィックは絵文字と自作アイコンのみで公式アートは含んでいません。公式イラストを使う場合は各キャラのCC0画像を差し込めます。CNP（CryptoNinja Partners）など派生プロジェクトのキャラを使う場合はそちらのライセンス条件を別途確認してください。
